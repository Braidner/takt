# Сценарий: из задачи словами в шаги съёмки

Человек описывает ролик обычными словами. Твоя работа — превратить это в шаги, которые
можно снять, и показать черновиком: сценарий правится до съёмки, потому что после она
стоит минут.

## Формат

```json
{
  "title": "Обзор системы",
  "task": "исходная задача словами",
  "steps": [{
    "label": "Виртуальные машины и контейнеры",
    "hint": "раздел «Система»: Proxmox, VM, контейнеры Docker",
    "actions": [{ "goto": "system" }, { "wait": 3500 }],
    "expect": "text=Виртуальные машины",
    "seconds": 11
  }]
}
```

- `label` — **титр для зрителя**: «Маршрут на очередь заказов», а не «проверяем таблицу».
  Это то, что появится в кадре;
- `hint` — что делает агент, видно только в студии;
- `actions` — `goto`, `click`, `type: {selector, text}`, `press`, `wait`, `waitFor`;
- `expect` — селектор, по которому видно, что шаг **действительно показал обещанное**;
- `seconds` — длительность шага, из них складывается хронометраж.

Отправка:

```bash
takt scenario draft.json          # черновиком, человек правит
takt scenario draft.json --ready  # утверждённым (обычно это делает человек кнопкой)
```

## expect — не перестраховка

Клик по пункту меню, который раскрывает подменю вместо перехода, проходит без ошибки:
элемент найден, клик выполнен, шаг «успешен». А в кадре остался прежний экран. Ролик
снимется целиком и покажет не то, что обещают титры — и заметишь ты это на смонтированном
результате, то есть после всей съёмки.

Поэтому шаг, который заявляет переход, обязан назвать признак, по которому переход виден.

## Ритм

- **Один экран — один шаг.** Пересъёмка отдельного шага дешевле пересъёмки сцены;
- **`seconds` с запасом на отрисовку.** Действия обычно быстрее, остаток доигрывается
  паузой; а вот не успевший прорисоваться экран портит кадр;
- **Титр живёт от своего шага до следующего**, минимум четыре секунды. Мигающие титры
  означают, что шаги идут слишком плотно;
- **Шаг без действий — это пауза на экране.** Так снимаются планы, где ничего не
  происходит, но зрителю нужно успеть прочитать.

## Возврат на главную

`{"goto": ""}` — переход на корень. Именно пустая строка, а не отсутствие поля: шаг без
`goto` никуда не переходит.

## Что не должно попадать в сценарий

Ты снимаешь чужую живую систему. Необратимое — удаление, отправка сообщения, платёж,
остановка сервиса — в сценарий не идёт, даже если человек описал это словами. Скажи об
этом прямо и предложи безопасный аналог: набрать текст, не отправляя; открыть форму, не
подтверждая.

Печать в поле без отправки — нормальный демонстрационный приём и ничего не создаёт.

## Правка сценария (`scenario_note`)

Человек описывает, что хочет изменить. Различай по стоимости:

- **подпись, длительность, порядок, удаление шага** — это данные, человек знает их лучше
  тебя, и он правит их сам в студии, без тебя;
- **«добавь шаг, где показано X»** — требует знания интерфейса, это твоя работа: разведай,
  найди селекторы, добавь шаг, отправь обновлённый сценарий черновиком.
