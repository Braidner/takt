# Монтаж и хайлайты

```bash
takt edit                      камера, курсор, титры, звук  → movie-cut.mp4
takt edit --no-zoom            без наездов (длинные списки, прокрутки)
takt edit --drift              медленный дрейф камеры вместо наездов (витрины, реклама)
takt edit --silent             без звука (когда поверх ляжет озвучка)
takt highlight                 ≈25 с из лучших моментов     → movie-short.mp4
takt highlight --vertical      9:16 для сторис              → movie-short-vertical.mp4
takt highlight --seconds 15    другая целевая длина
```

## Что делает монтаж

**Камера** наводится по координатам действий из телеметрии — их пишет съёмка, когда
кликает. Это принципиально отличается от экранных рекордеров с «умным зумом»: они
угадывают по движению пикселей и промахиваются, мы знаем точно. Наезд начинается за
0,9 с до клика и держится 1,9 с после; соседние действия сливаются в один план.

**Курсор** рисуется монтажом. Headless-съёмка его не пишет — синтетические клики не
двигают системный курсор. Без курсора зритель не понимает, что произошло действие.

**Титры** — картинки из `titles.mjs`, отрисованные браузером. Правка титра не требует
пересъёмки: перерисовать и пересобрать.

**Звук** синтезируется: подложка без мелодии, щелчки на действиях, автопригрушение.
Лицензионных хвостов нет, длительность подгоняется под ролик.

## Когда `--drift`

Наезд по клику работает там, где есть клики. На витрине с постерами, дашборде или
длинной странице кликать не по чему, а неподвижный кадр в рекламном ролике читается
как стоп-кадр — даже если на нём идёт загрузка. Дрейф даёт медленное движение по
каждой сцене со своим направлением: соседние планы не едут одинаково, иначе это
выглядит как заедание.

## Когда `--no-zoom`

Наезды хороши там, где есть точечные действия. Если ролик — это прокрутка длинного
списка или чтение большого экрана, камера будет ездить впустую: снимай без зума, общий
план сам по себе информативен.

## Хайлайты — другой жанр, а не обрезка

Полный ролик отвечает «как это работает» и его смотрят, когда уже интересно. Хайлайты
отвечают «что это вообще» — за время, которое человек тратит на незнакомое в ленте.

Моменты отбираются по смыслу, а не по количеству движения: действие важнее смены
экрана, смена важнее финального кадра. Куски не перекрываются, склеиваются
кроссфейдами, титры крупнее обычных — в ленте смотрят без звука.

Вертикальная версия **кадрируется**, а не сжимается: горизонтальный интерфейс в 9:16
целиком не влезает, и вписанная ленточка в четверть экрана нечитаема на телефоне.

## Порядок

```
takt shoot  →  takt build  →  takt edit  →  takt highlight
   съёмка       мастер        показ        лента
```

Мастер нужен после каждой съёмки — по нему работают в студии. Монтаж и хайлайты
считаются минуты, поэтому делаются, когда ролик принят.
