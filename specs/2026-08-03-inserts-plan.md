# Врезки: любые наложения поверх кадра — план внедрения

> Одна задача — один коммит.

**Цель:** поверх кадра можно положить произвольную графику — схему, диаграмму, плашку,
что угодно, — и она движется синхронно с роликом, кадр в кадр.

**Почему это важно.** Ролик показывает интерфейс, но объяснять часто нужно то, чего на
экране нет: как устроен обмен, откуда берутся данные, что произойдёт дальше. Врезка —
единственный способ сказать это, не выдумывая экран, которого не существует.

**Архитектура.** Врезка — обычный HTML или SVG в проекте (`inserts/<имя>.html`).
Композиция — это браузер, поэтому рисовать её нечем специальным: она вставляется в
сцену как есть. Единственное жёсткое требование — **детерминизм**: анимации не идут
сами по часам, их время выставляет композиция из номера кадра. Иначе покадровый привод
снимет рассинхрон, а скраббер покажет не то, что попадёт в файл.

## Глобальные ограничения

- Новых зависимостей нет.
- Скрипты во врезке не выполняются: они сломали бы детерминизм и открыли бы дыру в
  сборке. Только разметка, стили и анимации.
- Анимации управляются через Web Animations (`getAnimations`) и SMIL
  (`setCurrentTime`) — обе ставятся на время кадра и ставятся на паузу.
- Комментарии, сообщения и коммиты — по-русски.

## Формат

Эффект наложения получает вид `insert`:

```json
{ "id": "p02-ins1", "plan": "p02", "kind": "overlay",
  "at": { "from": 0.4, "to": 6.0 },
  "params": { "what": "insert", "src": "inserts/обмен.html", "place": "cover" },
  "source": "manual" }
```

`place`: `cover` — во весь кадр поверх интерфейса; `side` — правая половина, интерфейс
остаётся виден; `corner` — четверть в углу.
