# Ревизия конвейера — план внедрения

> **Для исполнителя:** одна задача — один коммит. Каждая заканчивается самостоятельно
> проверяемым результатом.

**Цель:** конвейер перестаёт врать. Время в студии совпадает с картинкой, справочники
описывают то, что есть, интерфейс не обещает несуществующего, а мёртвый код не притворяется
живым.

**Откуда взялось:** ревизия после стадии 5 нашла один настоящий разъезд шкал (мой,
внесённый вместе с заставкой), девять ложных утверждений в документации, шесть мёртвых
файлов и один полноценный интерфейс поверх функции, которой нет.

## Глобальные ограничения

- Новых зависимостей нет.
- `studio/compose/*.mjs` — без импортов Node.
- Одно место, где считается время. Если время появляется в двух местах — это баг,
  а не архитектура.
- Ничего не удаляется молча: удалённое либо не нужно, либо записано в хендофф как
  «не сделано».
- Комментарии, сообщения и коммиты — по-русски: почему, а не что.

### Задача 1: время считает раскадровка, а не композиция

**Дефект.** `buildFilm` ставит заставку первой и сдвигает все планы на 2,6 с, а `at`
планов в раскадровке считается без неё. Клик по плану ведёт на 2,6 с раньше, клипы всех
дорожек стоят не там, где картинка, замечание по таймкоду приезжает агенту с чужим
временем, дикторская реплика ляжет раньше своего титра.

**Файлы:** `studio/compose/duration.mjs` (константы карточек), `storyboard.mjs`
(`at` с учётом обложки), `film.mjs` (следует раскадровке), тесты всех трёх.

- [ ] Тест: `storyboard.plans[0].at === film.plans[1].from`; `seconds` включает обложку
      и финал; без обложки всё как было.
- [ ] Реализация, проверка в браузере (клик по плану попадает в свой план), коммит.

### Задача 2: версии ролика появляются без перезагрузки

**Дефект.** `POST /api/movie` рассылает то, что прислал клиент, а поле `cuts` добавляется
только при чтении с диска. После сборки и озвучки переключатель версий не обновляется.

**Файлы:** `studio/server.mjs`.

- [ ] Реализация, проверка `curl` + браузер, коммит.

---

### Задача 3: справочники не врут агенту

**Дефект.** Девять ложных утверждений. Опаснее прочих `references/shooting.md`: титры
якобы не выжигаются, `takt build` якобы обрезает вход через `trimmedStart`, каждая съёмка
якобы пишет webm, советуется увеличить `seconds` — поля, которого нет.

**Файлы:** `references/shooting.md`, `SKILL.md`, `cli.mjs`, `studio/server.mjs`,
`studio/export.mjs`, `studio/index.html`, `studio/live.js`, `studio/compose/apply.mjs`,
удалить `brainstorm-production.md`.

- [ ] Правка, сверка каждого утверждения с кодом, коммит.

### Задача 4: мёртвый код уходит

**Что мертво:** `capture/run.mjs`, `capture/probe.mjs`, `capture/retune-zoom.mjs`,
`capture/lib/recorder.mjs`, `capture/lib/actions.mjs` (два падают при запуске),
`studio/contrast.mjs`, ветки `movie-cut.mp4` и `movie-short-vertical.mp4` в `export.mjs`,
поле `states.json.live`, четыре неиспользуемых импорта.

`capture/lib/stend.mjs` живой — переезжает в `studio/lib/stend.mjs`, каталог `capture/`
исчезает вместе с записью в `package.json files`.

- [ ] Удаление, `npm test`, проверка `takt shoot` на стенде, коммит.

### Задача 5: врезки-схемы убираются из интерфейса

**Дефект.** Дорожка «Схемы», перетаскивание, перенос между планами, вид работы в плане
замечаний с оценкой «5 минут», вывод в экспорт — всё это поверх функции, которой нет:
в `compose/` слова `diagram` не существует. Рисовать схемы было чем, пока в поставке жил
Remotion; сейчас — нечем.

Идея остаётся в хендоффе как «не сделано»; интерфейс, обещающий её, уходит.

**Файлы:** `studio/live.js`, `index.html`, `app.js`, `server.mjs` (`/api/diagram-move`),
`classify-notes.mjs`, `compose/storyboard.mjs`, `studio/storyboard.mjs`, `export.mjs`,
`references/notes.md`, `references/storyboard.md`.

- [ ] Удаление, тесты, проверка в браузере, коммит.

### Задача 6: реплики создаются в студии

**Дефект.** Панель дикторского текста умеет только править существующие реплики, а
создать их нельзя ниоткуда, кроме прямого запроса агента, который нигде не описан.
`takt narrate` честно отвечает «текст пуст».

**Файлы:** `studio/narration.js`, `studio/live.js`, `studio/index.html`, `studio/app.js`,
`studio/styles.css`, `references/voice.md`.

Реплика заводится на план: её метка — начало плана, а хронометраж плана и есть окно,
в которое ей надо уложиться.

- [ ] Реализация, проверка в браузере, коммит.

### Задача 7: голос ложится поверх музыки, а не вместо

**Дефект.** `build-track.mjs` мапит только голосовую дорожку, и в `movie-vo.mp4`
пропадают подложка и щелчки, которые обещает `references/editing.md`.

**Файлы:** `studio/build-track.mjs`, `references/voice.md`.

Музыка под голосом пригрушается — тем же приёмом, каким она пригрушается под щелчками.

- [ ] Реализация, проверка на mc-медиа, коммит.

### Задача 8: первая ступень конвейера оживает

`prompt.txt` — исходник перегенерации по спеке, и он у нас есть: это `task` раскадровки.
Сервер пишет его при сохранении, ступень «задача» перестаёт быть вечным «ещё нет».

**Файлы:** `studio/server.mjs`.

- [ ] Реализация, проверка полосы ступеней, коммит.

### Задача 9: тесты на сервер

Сервер — 1014 строк без единого теста, при этом он единственный владелец данных проекта.

**Файлы:** `test/server.test.mjs`.

Поднимается на своём порту в своём `TAKT_HOME`, проверяются: миграция сценария в
раскадровку, нормализация при записи, `/api/approve` и ступени, замечание с адресом,
план работ.

- [ ] Тесты, коммит.
