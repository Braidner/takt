# `takt start` — единая точка входа

Дата: 2026-07-30. Статус: утверждено.

## Задача

Сегодняшний быстрый старт — три ручных шага: `npm install`, `npx playwright install
chromium`, `node cli.mjs serve`. Должно быть два: `npx skills add Braidner/takt`, затем
`/takt start` в агенте — и студия поднята в фоне, сайт открыт, агент сидит на событиях.

Ограничение, определившее дизайн: **skills CLI не исполняет команд** — он только копирует
или симлинкает файлы. Установка обязательных зависимостей поэтому живёт внутри `takt
start` и происходит при первом запуске.

Опциональные возможности (Remotion, озвучка) уже ставятся из панели «Окружение» в студии
через реестр `studio/registry.mjs` — это не меняется.

## Команда `takt start`

Новый оркестратор `studio/start.mjs`, в `cli.mjs` регистрируется как `start` (без флага
`studio:` — он сам поднимает студию). Последовательность:

1. **Bootstrap.** Нет `node_modules` → `npm install` (вывод наследуется, прогресс виден).
   Нет Chromium — проверка та же, что в `doctor` — → `npx playwright install chromium`.
   Повторные запуски проходят проверки мгновенно и ничего не качают.
2. **Студия в фоне.** Если `studioAlive()` — переиспользуем работающую. Иначе — spawn
   `server.mjs` c `detached: true` + `unref()`, stdout/stderr в лог-файл в `$TAKT_HOME`,
   затем ожидание `/api/hello` (с таймаутом). `start` завершается, сервер живёт.
3. **Открыть сайт.** `open` (macOS) / `xdg-open` (Linux) / `start` (Windows) на
   `http://localhost:4173`. Флаг `--no-open` подавляет — для повторных вызовов агентом.
4. Печать адреса и статуса одной строкой.

`serve` остаётся: это низкоуровневый форграунд-запуск сервера, его использует `start`,
и он нужен для отладки (видно живой лог).

`ffmpeg` bootstrap не ставит: системный пакет, нужен brew/apt и права. Его отсутствие
показывают `doctor` и панель «Окружение» — как сейчас.

## SKILL.md

Раздел «Запуск» переписывается:

```bash
takt start   # ставит недостающее, поднимает студию в фоне, открывает сайт
takt poll    # сразу после — сесть на события
```

Агент после `start` немедленно уходит в `poll` фоновой задачей: человек видит открытый
сайт и статус «агент на связи», а не инструкцию «откройте localhost:4173».

## README

Quick Start сжимается до двух шагов: `npx skills add Braidner/takt`, затем `/takt start`
в Claude Code. Ручной путь без агента — одной строкой: `node cli.mjs start`. Упоминания
`npm install && npx playwright install chromium` из Quick Start уходят; опциональные
установки описываются как «из панели „Окружение“».

## Ошибки

- `npm install` или установка Chromium упали → показать их вывод и остановиться,
  студию не поднимать.
- Порт занят живой студией → не ошибка, переиспользование.
- Порт занят чужим процессом (`/api/hello` не отвечает как студия) → понятное
  сообщение с подсказкой про `TAKT_PORT`.
- Сервер не ответил на `/api/hello` за таймаут → показать хвост лог-файла.

## Проверка

Руками, по сценариям:

1. Чистая установка (симлинк без `node_modules`) → `takt start` ставит всё и открывает
   сайт.
2. Повторный `takt start` при живой студии → мгновенно, второй сервер не поднимается.
3. `takt start --no-open` → сайт не открывается, остальное как обычно.
4. `takt poll` сразу после `start` → садится на события без «студия не запущена».
