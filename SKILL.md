# Takt — студия демонстрационных роликов

Ты не снимаешь ролик одной командой. Ты открываешь человеку рабочее место и **садишься
ждать его событий**: он описывает задачу словами, правит раскадровку, ставит замечания по
таймкодам, просит переснять сцену. Каждое действие приходит событием, ты его выполняешь
и возвращаешься ждать.

```bash
takt start   # поставить недостающее, поднять студию, открыть сайт
takt         # что сейчас с проектом: ступень, раскадровка, замечания
takt poll    # сесть на события (фоновой задачей)
```

## Дальше не читай — спрашивай

Всё остальное живёт в самом инструменте и приходит оттуда свежим:

| Что нужно | Команда |
|---|---|
| где мы сейчас | `takt` |
| список команд | `takt help` |
| что делает команда | `takt <команда> --help` |
| как делается часть работы | `takt playbook` → `takt playbook <id>` |
| что известно про снимаемую систему | `takt target` |

**Не пересказывай инструкции в этом файле.** Он специально ничего не знает про
внутренности: раскадровку, съёмку, монтаж, врезки, голос и разбор замечаний описывают
справочники, которые лежат рядом с кодом и меняются вместе с ним. Установленная копия
скилла отстать от них не может, потому что ей нечему отставать.

Причина не теоретическая. Пока инструкция жила отдельным документом, в ней накопилось
девять ложных утверждений: титры «не выжигаются» — выжигаются; сборка «обрезает вход» —
не обрезает; советовалось поле, которого нет. Заметил это человек на готовом ролике.

## Два правила, которые не выводятся из команд

**Ты просыпаешься с пустым контекстом.** Между событиями может пройти час, а разговора
ты не помнишь. Что знаешь про снимаемую систему — прочитай с диска (`takt target`), что
выяснил — запиши туда же. Не записал — значит не было, и следующая сессия будет
разведывать интерфейс заново.

**Стоимость правок различается на порядок.** Переписать титр — секунды, пересобрать
ролик — минуты, переснять сцену — десятки минут. Поэтому замечания сначала разбираются
по типу, а человеку показывается план с оценкой, и только потом идёт работа
(`takt playbook notes`).

## Ответ команды

Команды отвечают в TOON — это JSON без скобок и без повтора имён полей. Последняя
строка `help[]` называет следующий шаг готовой командой; следуй ей, а не памяти.
Код возврата `2` означает, что команду позвали неправильно: читай `takt <команда> --help`,
а не повторяй с другими данными.
